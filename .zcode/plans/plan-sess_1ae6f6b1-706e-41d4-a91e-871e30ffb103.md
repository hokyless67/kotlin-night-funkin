# Мобильная поддержка (Android + iOS): платформонезависимый код, тач, KMP-сборка

## Context

Проект — чистый kotlin-jvm (`korge-jvm:6.0.0`, `application`-плагин), весь код в `src/main/kotlin/nightfunkin/` (52 файла). Мобильных таргетов нет вообще. Платформозависимое (JVM-only): `java.io.File`-стриминг ассетов + `javax.imageio` фолбэк-PNG-декодер, ffmpeg через `ProcessBuilder` (катсцены), сохранка в `user.home`, `java.awt.Desktop.browse`, `System.getenv/getProperty/nanoTime`, `Dispatchers.IO`, потоки/`java.util.concurrent`, `gameWindow.setSize`. Инпут — 100% клавиатура (`KnfInput`), тача нет.

Решения пользователя: таргеты **Android + iOS**; ассеты — **папка, которую юзер кладёт сам** (Android: `Android/data/dev.hokyless.kotlinfunkin/files/`, iOS: Documents/KNF через File Sharing); видео — **скип на мобилках** (нативное декодирование = отдельный большой проект, абстракция оставляет дверь); тач — **базовый, в этом заходе**.

Правило работы: **только писать код** — не запускать, не собирать, не коммитить.

## 2. Платформенный слой (expect/actual), новые файлы в `nightfunkin/platform/`

**`KnfFile`** — синхронный файловый примитив (замена `java.io.File` во всём коде, НЕ suspend, чтобы не рябить по всем вызовам):
```kotlin
expect class KnfFile(path: String) {
    fun isFile(): Boolean; fun isDirectory(): Boolean
    fun readBytes(): ByteArray; fun readText(): String
    fun writeText(text: String): Boolean          // с созданием родительских папок
    fun listNames(): List<String>?                // null если не папка
    fun child(name: String): KnfFile; fun absolutePath(): String
}
```
- jvm/android actuals: обёртка над `java.io.File` (~40 строк каждый; на Android `java.io.File` есть и работает с app-папками).
- ios actual: POSIX (fopen/fread/opendir) через `platform.posix` + cinterop (~130 строк), блокирующе — как и сейчас на десктопе.

**`KnfPlatform`**:
```kotlin
expect object KnfPlatform {
    fun assetRootCandidates(): List<String>   // где искать assets, по предпочтению
    fun userFilesDir(): String                // запись knf-save.json
    val isMobile: Boolean
}
```
- jvm: текущие `ROOT_CANDIDATES` (`Funkin-0.8.6-Source/assets`, `assets`, `../assets`) + override из env `KNF_ASSETS` и `-Dknf.assets`; userFilesDir = `user.home`.
- android: context приложения (от korlibs-рантайма Android; при недоступности — кастомный entry-класс) → `getExternalFilesDir(null)/assets`, затем `filesDir/assets`; userFilesDir = `getExternalFilesDir(null) ?: filesDir`.
- ios: `NSHomeDirectory()/Documents/KNF/assets`; userFilesDir = `Documents/KNF`.

**`VideoBackend`** (видео-катсцены):
```kotlin
interface VideoBackend {
    val isSupported: Boolean
    suspend fun probe(path: String): VideoInfo?
    suspend fun openFrames(path: String): VideoFrames?      // nextFrame(): Bitmap32?
    suspend fun extractAudioWav(path: String): ByteArray?   // для MusicPlayer
}
expect val videoBackend: VideoBackend
```
- jvm actual: текущий ffmpeg-код целиком переносится из `VideoCutscene.kt` (ProcessBuilder, ffprobe, два демона-потока, ArrayBlockingQueue/CountDownLatch, temp WAV, Windows-поиск ffmpeg) — там JVM API легален.
- android/ios actual: `isSupported = false` → существующий graceful-skip (`VideoCutscene.kt:82-87`).
- `VideoCutscene.kt` остаётся в common, без java-импортов: потребляет `VideoFrames`, `System.nanoTime` → `PerformanceCounter.nanoseconds`, `Dispatchers.IO` → `Dispatchers.Default`.

## 3. Чистый PNG-декодер вместо ImageIO (`core/KnfPng.kt`, common, новый)

KorGE 6 PNG-декодер умеет только 8-bit RGBA (подтверждено `TODO("Bytes: $bpp")` в vendored korlibs `PNG.kt:408`), ImageIO на нативе нет. Пишем чистый Kotlin-декодер для типов 0 (grey), 2 (RGB), 3 (indexed+PLTE/tRNS), 4 (grey+alpha), глубины 1/2/4/8/16 (16→8), non-interlaced; inflate — через korlibs-compression (транзитивный деп korlibs-image; при отсутствии — добавить артефакт `com.soywiz.korlibs.korlibs:korlibs-compression:6.0.0`). Выдаёт `Bitmap32` с тем же переворотом каналов (0xAABBGGRR), что текущий ImageIO-путь (`KnfFiles.kt:262-279`), дальше существующий `premultiply()`. Диспетчеризация в `KnfFiles.decodeImage`: type 6/8bit → korlibs (быстрый путь), остальное → KnfPng.

## 4. Правки KnfFiles / Save / загрузчиков (механика)

- **`core/KnfFiles.kt`**: `File` → `KnfFile`, root из `KnfPlatform.assetRootCandidates()`, `listFiles()`-сканы → `listNames()`, выкинуть `javax.imageio`/`System.getProperty` (override через env `KNF_ASSETS` в jvm-актуале). API и вся логика resolve/библиотек/MP3-неготиации — без изменений.

## 6. Тач-управление (базовое)

**`core/KnfTouch.kt`** (новый, common) — глобальная шина: `object KnfTouch { val lanes = BooleanArray(4); var accept; var back; var uiUp/uiDown; var left/right; ... }`. Оверлеи пишут, `KnfInput` читает.

**`core/KnfInput.kt`**: в `update()` мержить клавиатуру с тачем (`isDownNow = keyboard || KnfTouch.lanes[lane]`), accept/back/uiUp/uiDown/letterSort — аналогично; `reset()` чистит и тач-стейт. Все 5 сцен-потребителей не меняются.

**`ui/TouchControls.kt`** (новый, common) — оверлей поверх сцены, вне `hudContainer` (не бьётся beat-zoom):
- Геймплей: 4 больших тач-зоны внизу, выровнены по колонкам струмлайна (x-позиции из `layoutStrumlines`, PlayScene.kt:638-664); мультитач; нажатие дёргает `KnfTouch.lanes` — рецепторы/хиты работают через существующий `processInput` без правок. Небольшая кнопка паузы в углу (`KnfTouch.pause`).
- Меню (Title/MainMenu/SongSelect/Result): тап = accept; вертикальный драг ≥40px = uiUp/uiDown с троттлингом; горизонтальный драг = justPressed лейнов 0/3 (сложность/сортировка в Freeplay). Позиции хит-теста в координатах 1280x720.
- Включение: автоматически на `KnfPlatform.isMobile`, плюс env `KNF_TOUCH=1` для теста на десктопе.
- Мультитач — через корутины touch-событий korlibs 6 (TouchEvent с per-pointer координатами; точный API све­рю по korge-jvm jar при реализации).

## 7. Android/iOS конфиг

- **Android**: applicationId `dev.hokyless.kotlinfunkin`, landscape, без спец-пермиссий (app-специфичные папки доступны без них). Ассеты: юзер кидает `assets/` в `Android/data/dev.hokyless.kotlinfunkin/files/`.

## Verification (выполняет пользователь — я код не запускаю)

1. Первая сборка: `gradlew build` — кэтч возможных нестыковок DSL korge-плагина (имена таргетов/тасков, версия serialization-плагина, ios source set) — правим по факту.
2. Десктоп-паритет: `gradlew runJvm` (или эквивалент плагина) — ассеты грузятся, indexed PNG не чёрные (циановая стрелка вниз = синяя, не жёлтая), сохранка читается, env-хуки (`KNF_SONG` и пр.) работают, видео-катсцена играет, мерч-линк открывается.
3. Тач на десктопе: `KNF_TOUCH=1` — мышью нажимаются тач-зоны, ноты бьются.
4. Android: `gradlew installAndroid` (таск плагина) на устройство, кинуть assets в `Android/data/dev.hokyless.kotlinfunkin/files/`, смоук: меню → песня → пауза; катсцена пропускается.
